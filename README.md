# Pokémon cards and Nintendo: one-day route page

Static page that lets a visitor pick one of three one-day routes (Akihabara cards and retro games, Akihabara then Shibuya for Nintendo, Pokémon Centers across the city). Generic version: no guest names, no dates.

- `python3 build.py` writes `index.html` (and `preview.html` with the device toggle) from `page.json`, `courses.json`, `photos.json`.
- Photos come from Wikimedia Commons; credits are listed at the bottom of the page.
